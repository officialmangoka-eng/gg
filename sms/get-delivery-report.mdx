## Endpoint

<Badge color="green">GET</Badge> `https://api.wapimax.com/sms/v1/status/{message_ref}`

## Authentication

Every request must include your API key in the `X-API-Key` header. See [Authorization](/get-started/authorization) to create one.

| Header | Value | Required |
| --- | --- | --- |
| `X-API-Key` | Your WapiMax API key | Yes |
| `Accept` | `application/json` | Recommended |

## Path parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `message_ref` | string | Yes | `message_id` returned when the SMS was sent |

## Response

<CodeGroup>

```json 200 OK
{
  "success": true,
  "status": 200,
  "state": "success",
  "message": "Delivery status retrieved.",
  "request_id": "REQUEST_ID",
  "data": {
    "message_id": "482193",
    "send_status": "accepted",
    "delivery_status": "delivered"
  }
}
```

</CodeGroup>

### Response fields

| Field | Type | Description |
| --- | --- | --- |
| `success` | boolean | Whether the request succeeded |
| `status` | integer | HTTP status code |
| `state` | string | Request state |
| `message` | string | Result message |
| `request_id` | string | Request ID for support |
| `data.message_id` | string | Message reference |
| `data.send_status` | string | Provider submission state |
| `data.delivery_status` | string | Latest delivery state |

### Status values

| Field | Value | Description |
| --- | --- | --- |
| `send_status` | `accepted` | Provider accepted the SMS |
| `send_status` | `failed` | Provider rejected the SMS |
| `send_status` | `unknown` | Provider result not confirmed |
| `delivery_status` | `pending` | Delivery in progress |
| `delivery_status` | `delivered` | Delivered to the handset |
| `delivery_status` | `failed` | Delivery failed |
| `delivery_status` | `unknown` | Delivery state not confirmed |

## Errors

| Status | Description |
| --- | --- |
| `400` | Invalid message reference |
| `401` | Missing or invalid API key |
| `404` | Message not found |
| `409` | No provider message ID, so no delivery report is available |
| `429` | Too many failed requests. Retry after `Retry-After` seconds |
| `502` | Provider delivery report unavailable. Retry later |
| `503` | Service temporarily unavailable. Retry shortly |

## Notes

- Replace `{message_ref}` with the `message_id` from [Send a single SMS](/sms/send-single-sms) or [Send bulk SMS](/sms/send-bulk-sms).
- `send_status` can be `accepted` while `delivery_status` is still `pending`.
