## Endpoint

<Badge color="blue">POST</Badge> `https://api.wapimax.com/email/v1/transactional/send`

<Warning>
  You need an active sender address (e.g. `support@yourcompany.com`) registered in your WapiMax account. To create one or more, go to **Dashboard → Communication → Email → Email Addresses**. Emails from unregistered sender addresses are rejected.
</Warning>

## Authentication

Every request must include your API key in the `X-API-Key` header. See [Authorization](/get-started/authorization) to create one.

| Header | Value | Required |
| --- | --- | --- |
| `X-API-Key` | Your WapiMax API key | Yes |
| `Content-Type` | `application/json` | Yes |
| `Accept` | `application/json` | Recommended |
| `Idempotency-Key` | Unique key for this send, max 100 characters | No |

## Request body

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `from` | string | Yes | Verified sender address in your WapiMax account |
| `from_name` | string | No | Sender display name |
| `to` | string | Yes | Recipient email address |
| `to_name` | string | No | Recipient display name |
| `cc` | array | No | CC [recipient objects](#recipient-object), max 100 |
| `bcc` | array | No | BCC [recipient objects](#recipient-object), max 100 |
| `reply_to` | string | No | Reply-to address |
| `reply_to_name` | string | No | Reply-to display name |
| `subject` | string | Yes | 1 to 500 characters, no line breaks |
| `html` | string | Conditional | HTML body, max 2 MiB. Required if `text` is not set |
| `text` | string | Conditional | Plain-text body, max 2 MiB. Required if `html` is not set |
| `attachments` | array | No | [Attachment objects](#attachment-object) |
| `inline_images` | array | No | [Inline image objects](#inline-image-object) |
| `track_opens` | boolean | No | Enable open tracking |
| `track_clicks` | boolean | No | Enable click tracking |
| `idempotency_key` | string | No | Max 100 characters. Must match the `Idempotency-Key` header if both are sent |

### Recipient object

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `email` | string | Yes | Recipient email address |
| `name` | string | No | Recipient display name |

### Attachment object

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `name` | string | Yes | Filename, without a path |
| `mime_type` | string | Yes | MIME type, e.g. `application/pdf` |
| `content` | string | Yes | Base64-encoded file content |

### Inline image object

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `cid` | string | Yes | Content ID used in `html` as `cid:<cid>` |
| `name` | string | No | Filename. Derived from `cid` if omitted |
| `mime_type` | string | Yes | Image MIME type, e.g. `image/png` |
| `content` | string | Yes | Base64-encoded image content |

### Response fields

| Field | Type | Description |
| --- | --- | --- |
| `success` | boolean | Whether the request succeeded |
| `status` | integer | HTTP status code |
| `state` | string | Request state |
| `message` | string | Result message |
| `request_id` | string | Request ID for support |
| `data.message_id` | string | Message reference |
| `data.to` | string | Recipient address |
| `data.send_status` | string | Provider acceptance state |
| `data.delivery_status` | string | Initial delivery state |

## Errors

| Status | Description |
| --- | --- |
| `400` | Invalid JSON, field, recipient, attachment or idempotency key |
| `401` | Missing or invalid API key |
| `402` | Insufficient wallet balance |
| `403` | Account inactive, no email plan, free allowance used up, or sender not registered or verified |
| `409` | Idempotency key reused with a different request |
| `413` | Request, body, attachments or message too large |
| `415` | `Content-Type` must be `application/json` |
| `429` | Too many failed requests. Retry after `Retry-After` seconds |
| `502` | Provider did not accept the request |
| `503` | Service temporarily unavailable. Retry with the same `Idempotency-Key` |

## Notes

- `202` means accepted for processing, not delivered.
- Unknown fields are rejected. Max request size is 20 MiB.
- If only `html` or `text` is sent, the other is generated. Send both for best compatibility.
- Attachments and inline images: max 60 combined and 10 MB decoded. Executable file types are blocked.
- Reuse the same `Idempotency-Key` when retrying the same request.
- Your free monthly allowance is used first, then your USD wallet is charged per recipient.
- Include `request_id` when contacting support.
