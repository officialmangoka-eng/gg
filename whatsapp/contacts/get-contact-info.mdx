---

## Endpoint

<Badge color="blue">POST</Badge> `https://api.wapimax.com/whatsapp/v1/sessions/{session_id}/contacts/info`

## Authentication

Every request must include your API key in the `X-API-Key` header. See [Authorization](/get-started/authorization) to create one.

| Header | Value | Required |
| --- | --- | --- |
| `X-API-Key` | Your WapiMax API key | Yes |
| `Content-Type` | `application/json` | Yes |
| `Accept` | `application/json` | Recommended |

## Path parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `session_id` | string | Yes | ID of the session |

## Request body

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `phones` | array of strings | Yes | Phone number, JID or LID of the contact. See [Contact formats](#contact-formats) |

<CodeGroup>

```json Example
{
  "phones": ["254712345678", "254701234567"]
}
```

</CodeGroup>

## Contact formats

Each entry in `phones` accepts the following formats.

| Format | Example | Description |
| --- | --- | --- |
| Phone number | `254712345678` | Full international number with country code |
| User JID | `254712345678@s.whatsapp.net` | WhatsApp user ID |
| LID | `100000012345678@lid` | WhatsApp Linked ID |

## Response

<CodeGroup>

```json 200 OK
{
  "contacts": [
    {
      "jid": "254712345678@s.whatsapp.net",
      "is_registered": true,
      "is_business": false,
      "lid": "100000012345678@lid",
      "picture_id": "ABCD1234",
      "status": "Available"
    }
  ]
}
```

</CodeGroup>

### Response fields

| Field | Type | Description |
| --- | --- | --- |
| `contacts` | array | List of contact info objects |
| `contacts[].jid` | string | WhatsApp JID of the contact |
| `contacts[].is_registered` | boolean | Whether the number is registered on WhatsApp |
| `contacts[].is_business` | boolean | Whether the contact is a business account |
| `contacts[].lid` | string or null | LID of the contact |
| `contacts[].picture_id` | string or null | Picture identifier for the contact |
| `contacts[].status` | string or null | About text of the contact |

## Errors

| Status | Description |
| --- | --- |
| `400` | Invalid request or missing `phones` array |
| `401` | Missing or invalid API key |
| `403` | Access to this session is not permitted |
| `404` | Session not found |
| `429` | Plan usage quota exceeded or rate limit exceeded |
| `503` | Session is not connected |

## Notes

- Replace `{session_id}` with your session ID. Get it from [List Sessions](/whatsapp/sessions/list-sessions).
- The request takes a `phones` array and the response returns a `contacts` array.
- `lid`, `picture_id` and `status` may be null if the information is not available.
- To fetch the actual profile picture, use [Get Profile Picture](/whatsapp/contacts/get-profile-picture).
