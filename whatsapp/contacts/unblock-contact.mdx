---
title: "Unblock Contact"
description: "Remove a contact from your WhatsApp session's block list so messages and calls can come through again."
---

## Endpoint

<Badge color="blue">POST</Badge> `https://api.wapimax.com/whatsapp/v1/sessions/{session_id}/blocking/unblock`

## Authentication

Every request must include your API key in the `X-API-Key` header. See [Authorization](/get-started/authorization) to create one.

| Header | Value | Required |
| --- | --- | --- |
| `X-API-Key` | Your WapiMax API key | Yes |
| `Content-Type` | `application/json` | Yes |
| `Accept` | `application/json` | Recommended |

## Path parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `session_id` | string | Yes | ID of the session |

## Contact formats

The `jid` body field accepts the following formats.

| Format | Example | Description |
| --- | --- | --- |
| Phone number | `254712345678` | Full international number with country code |
| User JID | `254712345678@s.whatsapp.net` | WhatsApp user ID |
| LID | `100000012345678@lid` | WhatsApp Linked ID |

## Request body

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `jid` | string | Yes | Phone number, JID or LID of the contact. See [Contact formats](#contact-formats) |

  "jid": "254712345678"

## Response

<CodeGroup>

```json 200 OK
{
  "success": true,
  "message": "Contact unblocked"
}
```

</CodeGroup>

### Response fields

| Field | Type | Description |
| --- | --- | --- |
| `success` | boolean | Whether the request succeeded |
| `message` | string | Result message |

## Errors

| Status | Description |
| --- | --- |
| `400` | Invalid or missing JID |
| `401` | Missing or invalid API key |
| `403` | Access to this session is not permitted |
| `404` | Session or contact not found |
| `429` | Plan usage quota exceeded or rate limit exceeded |
| `503` | Session is not connected |

## Notes

- Replace `{session_id}` with your session ID. Get it from [List Sessions](/whatsapp/sessions/list-sessions).
- Verify the result with [Check Block Status](/whatsapp/contacts/check-block-status).
