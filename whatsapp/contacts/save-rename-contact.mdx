---
title: "Save / Rename Contact"
description: "Save a new contact or update an existing name in the session's address book. Changes sync automatically to other devices linked to the same WhatsApp account."
---

## Endpoint

<Badge color="orange">PUT</Badge> `https://api.wapimax.com/whatsapp/v1/sessions/{session_id}/contacts/{jid}`

## Authentication

Every request must include your API key in the `X-API-Key` header. See [Authorization](/get-started/authorization) to create one.

| Header | Value | Required |
| --- | --- | --- |
| `X-API-Key` | Your WapiMax API key | Yes |
| `Content-Type` | `application/json` | Yes |
| `Accept` | `application/json` | Recommended |

## Path parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `session_id` | string | Yes | ID of the session |
| `jid` | string | Yes | Phone number or JID of the contact. See [Contact formats](#contact-formats) |

## Request body

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `first_name` | string or null | No | Short or first name. Omitted fields are not changed |
| `full_name` | string or null | No | Display name |
| `save_on_primary_addressbook` | boolean | No | When `true`, also saves to the phone's primary address book |

<CodeGroup>

```json Example
{
  "first_name": "Jane",
  "full_name": "Jane Doe",
  "save_on_primary_addressbook": true
}
```

```json Rename
{
  "full_name": "Jane Wanjiku"
}
```

</CodeGroup>

## Contact formats

The `jid` path parameter accepts the following formats.

| Format | Example | Description |
| --- | --- | --- |
| Phone number | `254712345678` | Full international number with country code |
| User JID | `254712345678@s.whatsapp.net` | WhatsApp user ID |
| LID | `100000012345678@lid` | Not supported on this endpoint |

## Response

<CodeGroup>

```json 200 OK
{
  "success": true,
  "message": "Contact saved"
}
```

</CodeGroup>

### Response fields

| Field | Type | Description |
| --- | --- | --- |
| `success` | boolean | Whether the request succeeded |
| `message` | string | Result message |

## Errors

| Status | Description |
| --- | --- |
| `400` | Missing name or JID is not a phone-number JID |
| `401` | Missing or invalid API key |
| `403` | Access to this session is not permitted |
| `404` | Session not found |
| `429` | Plan usage quota exceeded or rate limit exceeded |
| `503` | Session is not connected |

## Notes

- Replace `{session_id}` with your session ID. Get it from [List Sessions](/whatsapp/sessions/list-sessions).
- LIDs return a `400` error. Use only a phone number or user JID.
- Send only `full_name` to rename a contact.
- Use `save_on_primary_addressbook` to also save the contact to the phone's primary address book.
