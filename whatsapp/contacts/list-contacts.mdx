## Endpoint

<Badge color="green">GET</Badge> `https://api.wapimax.com/whatsapp/v1/sessions/{session_id}/contacts`

## Authentication

Every request must include your API key in the `X-API-Key` header. See [Authorization](/get-started/authorization) to create one.

| Header | Value | Required |
| --- | --- | --- |
| `X-API-Key` | Your WapiMax API key | Yes |
| `Accept` | `application/json` | Recommended |

## Path parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `session_id` | string | Yes | ID of the session |

## Query parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `q` | string | No | Search by contact name or phone number |
| `limit` | integer | No | Number of contacts to return. Range: 1-1000. Default: 100 |
| `offset` | integer | No | Number of contacts to skip. Default: 0 |

</CodeGroup>

### Response fields

| Field | Type | Description |
| --- | --- | --- |
| `contacts` | array | List of contacts |
| `contacts[].jid` | string | WhatsApp JID of the contact |
| `contacts[].phone` | string or null | Phone number when available |
| `contacts[].first_name` | string or null | First name of the contact |
| `contacts[].full_name` | string or null | Full name of the contact |
| `contacts[].push_name` | string or null | Name from the contact's WhatsApp profile |
| `contacts[].business_name` | string or null | Business name if the contact is a business |
| `contacts[].lid_jid` | string or null | Associated LID JID |
| `contacts[].source` | string | Where the record was learned, e.g. `appstate` |
| `contacts[].updated_at` | string or null | Latest stored update, ISO 8601 format |
| `total` | integer | Total number of matching contacts |
| `limit` | integer | Number of contacts returned in this page |
| `offset` | integer | Number of contacts skipped |

## Errors

| Status | Description |
| --- | --- |
| `400` | Invalid query parameters |
| `401` | Missing or invalid API key |
| `403` | Access to this session is not permitted |
| `404` | Session not found |
| `429` | Plan usage quota exceeded or rate limit exceeded |
| `503` | Session is not connected |

## Notes

- Replace `{session_id}` with your session ID. Get it from [List Sessions](/whatsapp/sessions/list-sessions).
- The list is a local cache and may not include every contact on the phone yet.
- Use `q` to search by name or phone.
- Use `limit` and `offset` to paginate, e.g. `GET .../contacts?q=jane&limit=50&offset=0`.
