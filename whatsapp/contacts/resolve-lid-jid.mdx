---
title: "Resolve LID/JID to Phone Number"
description: "Look up the stored mapping between a WhatsApp LID and a phone number. Read from the session's learned data without triggering a network lookup."
---

## Endpoint

<Badge color="green">GET</Badge> `https://api.wapimax.com/whatsapp/v1/sessions/{session_id}/contacts/{jid}/lid`

## Authentication

Every request must include your API key in the `X-API-Key` header. See [Authorization](/get-started/authorization) to create one.

| Header | Value | Required |
| --- | --- | --- |
| `X-API-Key` | Your WapiMax API key | Yes |
| `Accept` | `application/json` | Recommended |

## Path parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `session_id` | string | Yes | ID of the session |
| `jid` | string | Yes | Phone number, JID or LID of the contact. See [Contact formats](#contact-formats) |

## Contact formats

The `jid` path parameter accepts the following formats.

| Format | Example | Description |
| --- | --- | --- |
| Phone number | `254712345678` | Full international number with country code |
| User JID | `254712345678@s.whatsapp.net` | WhatsApp user ID |
| LID | `100000012345678@lid` | WhatsApp Linked ID |

## Response

<CodeGroup>

```json 200 OK
{
  "lid": "100000012345678",
  "phone_number": "254712345678",
  "created_at": 1794911400,
  "learning_source": "usync"
}
```

</CodeGroup>

### Response fields

| Field | Type | Description |
| --- | --- | --- |
| `lid` | string | The user part of the LID, without `@lid` |
| `phone_number` | string | Phone number without `@s.whatsapp.net` |
| `created_at` | integer | Unix timestamp in seconds when the mapping was first learned |
| `learning_source` | string | How the mapping was learned, e.g. `usync`, a peer's message, or pairing |

## Errors

| Status | Description |
| --- | --- |
| `400` | Invalid JID |
| `401` | Missing or invalid API key |
| `403` | Access to this session is not permitted |
| `404` | Session not found or no mapping known for this JID |
| `429` | Plan usage quota exceeded or rate limit exceeded |
| `503` | Session is not connected |

## Notes

- Replace `{session_id}` with your session ID. Get it from [List Sessions](/whatsapp/sessions/list-sessions).
- This endpoint reads an already-learned mapping. It does not trigger a new lookup.
- A connected session can still return `404` if the pair was never observed.
