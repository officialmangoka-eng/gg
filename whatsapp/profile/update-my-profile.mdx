title: "Update My Profile"
description: "Update the linked WhatsApp account's profile with a new display name, about text, emoji or profile picture."
---

## Endpoint

<Badge color="orange">PUT</Badge> `https://api.wapimax.com/whatsapp/v1/sessions/{session_id}/profile`

## Authentication

Every request must include your API key in the `X-API-Key` header. See [Authorization](/get-started/authorization) to create one.

| Header | Value | Required |
| --- | --- | --- |
| `X-API-Key` | Your WapiMax API key | Yes |
| `Content-Type` | `application/json` | Yes |
| `Accept` | `application/json` | Recommended |

## Path parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `session_id` | string | Yes | ID of the session |

## Request body

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `name` | string | No | Display name, 1 to 25 characters |
| `about` | string | No | About text, max 139 characters. `""` clears it |
| `about_emoji` | string | No | Emoji shown with About. Ignored when `about` is empty |
| `picture` | object | No | New profile picture. See [Picture formats](#picture-formats) |

### Picture formats

| Format | Fields |
| --- | --- |
| URL | `url` |
| Base64 | `data`, `mimetype` (e.g. `image/jpeg`, `image/png`) |

Images are center-cropped to square and re-encoded as JPEG.

## Response

<CodeGroup>

```json 200 OK
{
  "success": true,
  "message": "Profile updated"
}
```

</CodeGroup>

### Response fields

| Field | Type | Description |
| --- | --- | --- |
| `success` | boolean | Whether the request succeeded |
| `message` | string | Result message |

## Errors

| Status | Description |
| --- | --- |
| `400` | No fields supplied or invalid values |
| `401` | Missing or invalid API key |
| `403` | Access to this session is not permitted |
| `404` | Session not found |
| `429` | Plan usage quota exceeded or rate limit exceeded |
| `503` | Session is not connected |

## Notes

- Replace `{session_id}` with your session ID. Get it from [List Sessions](/whatsapp/sessions/list-sessions).
- Send only the fields you want to change. Omitted fields are left unchanged.
