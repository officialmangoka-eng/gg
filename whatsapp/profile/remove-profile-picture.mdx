---
title: "Remove Profile Picture"
description: "Remove the profile picture from the linked WhatsApp account without changing the display name or about text."
---

## Endpoint

<Badge color="red">DELETE</Badge> `https://api.wapimax.com/whatsapp/v1/sessions/{session_id}/profile/picture`

## Authentication

Every request must include your API key in the `X-API-Key` header. See [Authorization](/get-started/authorization) to create one.

| Header | Value | Required |
| --- | --- | --- |
| `X-API-Key` | Your WapiMax API key | Yes |
| `Accept` | `application/json` | Recommended |

## Path parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `session_id` | string | Yes | ID of the session |

## Response

<CodeGroup>

```json 200 OK
{
  "success": true,
  "message": "Profile picture removed"
}
```

</CodeGroup>

### Response fields

| Field | Type | Description |
| --- | --- | --- |
| `success` | boolean | Whether the request succeeded |
| `message` | string | Result message |

## Errors

| Status | Description |
| --- | --- |
| `401` | Missing or invalid API key |
| `403` | Access to this session is not permitted |
| `404` | Session not found |
| `429` | Plan usage quota exceeded or rate limit exceeded |
| `503` | Session is not connected |

## Notes

- Replace `{session_id}` with your session ID. Get it from [List Sessions](/whatsapp/sessions/list-sessions).
- Name and About are not changed by this endpoint.
- To set a new picture use [Update My Profile](/whatsapp/profile/update-my-profile).
