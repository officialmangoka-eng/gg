---
title: "Send Media"
description: "Send images, videos, audio files, and documents to WhatsApp contacts or groups through a linked session."
---

## Endpoint

<Badge color="blue">POST</Badge> `https://api.wapimax.com/whatsapp/v1/sessions/{session_id}/messages/image`

<Badge color="blue">POST</Badge> `https://api.wapimax.com/whatsapp/v1/sessions/{session_id}/messages/video`

<Badge color="blue">POST</Badge> `https://api.wapimax.com/whatsapp/v1/sessions/{session_id}/messages/audio`

<Badge color="blue">POST</Badge> `https://api.wapimax.com/whatsapp/v1/sessions/{session_id}/messages/document`

## Authentication

Every request must include your API key in the `X-API-Key` header. See [Authorization](/get-started/authorization) to create one.

| Header | Value | Required |
| --- | --- | --- |
| `X-API-Key` | Your WapiMax API key | Yes |
| `Content-Type` | `application/json` | Yes |
| `Accept` | `application/json` | Recommended |

## Path parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `session_id` | string | Yes | ID of the session used to send the media |

## Request body

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `to` | string | Yes | Contact phone number or group ID. See [Recipients](#recipients) |
| `image` / `video` / `audio` / `document` | object | Yes | Media object. Use the key that matches the endpoint |
| `caption` | string | No | Caption text. Image, video, and document only |
| `filename` | string | No | File name shown to the recipient. Document only |
| `ptt` | boolean | No | Set to `true` to send audio as a voice note. Audio only |

### Recipients

| Recipient | `to` format | Example |
| --- | --- | --- |
| Contact | Phone number | `254712345678` |
| Group | Group ID | `120363012345678901@g.us` |

### Media object

Provide either a public URL or Base64 data.

| Field | Type | Description |
| --- | --- | --- |
| `url` | string | Public URL of the file |
| `data` | string | Base64-encoded file. Use instead of `url` |
| `mimetype` | string | MIME type of the file. Required with `data` |

## Response

<CodeGroup>

```json 200 OK
{
  "status": "sent",
  "message_id": "3EB0C8F1A2B3C4D5E6",
  "timestamp": 1794304083,
  "to": "254712345678"
}
```

</CodeGroup>

### Response fields

| Field | Type | Description |
| --- | --- | --- |
| `status` | string | Sending status |
| `message_id` | string | Unique ID of the sent message |
| `timestamp` | integer | Sent time (Unix) |
| `to` | string | Recipient phone number or group ID |

## Errors

| Status | Description |
| --- | --- |
| `400` | Invalid request or missing required parameters |
| `401` | Missing or invalid API key |
| `403` | Access to this session is not permitted |
| `404` | Session not found |
| `413` | Media file exceeds the maximum file size allowed by your plan |
| `422` | Media file is unavailable or its metadata cannot be retrieved |
| `429` | Plan usage quota exceeded or rate limit exceeded. |
| `503` | Session is not connected |
|  |  |
|  |  |

## Notes

- For contacts, send digits only with the country code. Do not add `+`.
- For groups, the session must be a member/admin of the group.
- The media key must match the endpoint. For example, `/messages/video` expects a `video` object.
- Send either `url` or `data` in the media object, not both.
- Media URLs must be publicly reachable. Private or expired links fail.
- When sending Base64, `mimetype` must match the actual file type.
- Replace `SESSION_ID` with your session ID. Get it from [List Sessions](/whatsapp/sessions/list-sessions).
