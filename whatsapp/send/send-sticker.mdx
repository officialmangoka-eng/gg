## Endpoint

<Badge color="blue">POST</Badge> `https://api.wapimax.com/whatsapp/v1/sessions/{session_id}/messages/sticker`

## Authentication

Every request must include your API key in the `X-API-Key` header. See [Authorization](/get-started/authorization) to create one.

| Header | Value | Required |
| --- | --- | --- |
| `X-API-Key` | Your WapiMax API key | Yes |
| `Content-Type` | `application/json` | Yes |
| `Accept` | `application/json` | Recommended |

## Path parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `session_id` | string | Yes | ID of the session |

## Request body

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `to` | string | Yes | Phone number or group ID. |
| `sticker` | object | Yes | Sticker source: `url`, or `data` with `mimetype` |

### Sticker source

| Parameter | Type | Description |
| --- | --- | --- |
| `url` | string | Public URL of the sticker |
| `data` | string | Base64 encoded sticker |
| `mimetype` | string | MIME type, required with `data` |

### Recipients

| Recipient | `to` format | Example |
| --- | --- | --- |
| Contact | Phone number | `254712345678` |
| Group | Group ID | `120363012345678901@g.us` |

## Response

<CodeGroup>

```json 200 OK
{
  "status": "sent",
  "message_id": "3EB0C8F1A2B3C4D5E6",
  "timestamp": 1794304083,
  "to": "254712345678"
}
```

</CodeGroup>

### Response fields

| Field | Type | Description |
| --- | --- | --- |
| `status` | string | Sending status |
| `message_id` | string | Unique ID of the sent message |
| `timestamp` | integer | Sent time (Unix) |
| `to` | string | Recipient phone number or group ID |

## Errors

| Status | Description |
| --- | --- |
| `400` | Invalid request or missing required parameters |
| `401` | Missing or invalid API key |
| `403` | Access to this session is not permitted |
| `404` | Session not found |
| `429` | Plan usage quota exceeded or rate limit exceeded. |
| `503` | Session is not connected |

## Notes

- For contacts, send digits only with the country code. Do not add `+` or a WhatsApp suffix.
- For groups, the session must be a member of the group.
- Replace `{session_id}` with your session ID. Get it from [List Sessions](/whatsapp/sessions/list-sessions).
- The `mimetype` field is required when using Base64 `data`.
- Use a WebP file for best sticker compatibility.
