## Endpoint

<Badge color="blue">POST</Badge> `https://your-server.com/webhook`

WapiMax sends a POST request to your webhook URL when a subscribed event occurs.

## Envelope

<CodeGroup>

```json Payload
{
  "session_id": "my-session",
  "event": "message",
  "timestamp": 1767143203,
  "data": {}
}
```

</CodeGroup>

| Field | Type | Description |
| --- | --- | --- |
| `session_id` | string | Session that generated the event |
| `event` | string | Event name |
| `timestamp` | integer | Unix time in seconds |
| `data` | object | Event data |
| `offline` | boolean | `message` only. Replayed from the offline window. |

## Signature verification

When a secret is set, requests are signed with HMAC-SHA256.

| Header | Value |
| --- | --- |
| `X-Webhook-Timestamp` | Unix time |
| `X-Webhook-Signature` | `sha256=` + hex digest |
| `X-Webhook-Signature-Version` | `v2` |

Signed content: `{timestamp}.{raw_request_body}`

<CodeGroup>

```javascript Node.js
const crypto = require("crypto");

function verifyWebhook(secret, rawBody, signature, timestamp) {
  const expectedSignature = crypto
    .createHmac("sha256", secret)
    .update(`${timestamp}.${rawBody}`)
    .digest("hex");

  const signatureBuf = Buffer.from(signature.replace("sha256=", ""), "hex");
  const expectedBuf = Buffer.from(expectedSignature, "hex");

  if (signatureBuf.length !== expectedBuf.length) return false;

  return crypto.timingSafeEqual(signatureBuf, expectedBuf);
}
```

```python Python
import hmac
import hashlib

def verify_webhook(secret, raw_body, signature, timestamp):
    sig = signature.replace("sha256=", "")
    expected = hmac.new(
        secret.encode(),
        f"{timestamp}.{raw_body}".encode(),
        hashlib.sha256,
    ).hexdigest()
    return hmac.compare_digest(expected, sig)
```

```php PHP
function verifyWebhook(string $secret, string $rawBody, string $signature, string $timestamp): bool
{
    $sig = str_replace("sha256=", "", $signature);
    $expected = hash_hmac("sha256", $timestamp . "." . $rawBody, $secret);
    return hash_equals($expected, $sig);
}
```

</CodeGroup>

## Best practices

- Verify using the raw body. Do not re-serialize JSON.
- Reject stale timestamps.
- Return 2xx promptly and process in the background.
- Deliveries may be retried. Deduplicate `message` events by `data.message_id`.
