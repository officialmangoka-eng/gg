---

## Endpoint

<Badge color="green">GET</Badge> `https://api.wapimax.com/whatsapp/v1/sessions/{session_id}/webhooks`

## Authentication

Every request must include your API key in the `X-API-Key` header. See [Authorization](/get-started/authorization) to create one.

| Header | Value | Required |
| --- | --- | --- |
| `X-API-Key` | Your WapiMax API key | Yes |
| `Accept` | `application/json` | Recommended |

## Path parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `session_id` | string | Yes | ID of the session |

## Response

<CodeGroup>

```json 200 OK
{
  "webhooks": [
    {
      "id": "webhook-uuid",
      "url": "https://example.com/whatsapp",
      "events": [
        "message",
        "connected"
      ],
      "secret": null,
      "enabled": true
    }
  ],
  "count": 1
}
```

</CodeGroup>

### Response fields

| Field | Type | Description |
| --- | --- | --- |
| `webhooks` | array | Webhook configurations |
| `webhooks[].id` | string | Webhook ID |
| `webhooks[].url` | string | Destination URL |
| `webhooks[].events` | array | Subscribed events |
| `webhooks[].secret` | string | Signing secret, may be null |
| `webhooks[].enabled` | boolean | Whether enabled |
| `count` | integer | Number returned |

## Errors

| Status | Description |
| --- | --- |
| `401` | Missing or invalid API key |
| `403` | Access to this session is not permitted |
| `404` | Session not found |
| `429` | Plan usage quota exceeded or rate limit exceeded |
| `503` | Session is not connected |

## Notes

- Replace `{session_id}` with your session ID. Get it from [List Sessions](/whatsapp/sessions/list-sessions).
- Webhooks are registered in the dashboard. See [Register Webhook](/whatsapp/webhooks/register-webhook).
