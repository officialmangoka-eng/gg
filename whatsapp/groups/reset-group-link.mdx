---
title: "Reset Group Link"
description: "Revoke the current invite link and generate a fresh one instantly. Shut out unwanted joins when a link has been shared too widely."
---

## Endpoint

<Badge color="green">GET</Badge> `https://api.wapimax.com/whatsapp/v1/sessions/{session_id}/groups/{group_jid}/invite-link?reset=true`

## Authentication

Every request must include your API key in the `X-API-Key` header. See [Authorization](/get-started/authorization) to create one.

| Header | Value | Required |
| --- | --- | --- |
| `X-API-Key` | Your WapiMax API key | Yes |
| `Accept` | `application/json` | Recommended |

## Path parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `session_id` | string | Yes | ID of the session |
| `group_jid` | string | Yes | JID of the group, ends in `@g.us` |

## Query parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `reset` | boolean | Yes | Must be set to `true` to generate a new invite link and invalidate the previous one |

## Response

```json 200 OK
{
  "invite_link": "https://chat.whatsapp.com/NewInviteCode123"
}
```

</CodeGroup>

### Response fields

| Field | Type | Description |
| --- | --- | --- |
| `invite_link` | string | The new WhatsApp invite link for the group |

## Errors

| Status | Description |
| --- | --- |
| `401` | Missing or invalid API key |
| `403` | Access to this session is not permitted |
| `404` | Session or group not found |
| `429` | Plan usage quota exceeded or rate limit exceeded |
| `503` | Session is not connected |

## Notes

- Replace `{session_id}` with your session ID. Get it from [List Sessions](/whatsapp/sessions/list-sessions).
- Replace `{group_jid}` with the group JID. Get it from [List Groups](/whatsapp/groups/list-groups) or [Create Group](/whatsapp/groups/create-group).
- Use the group JID returned by the API. Do not use the group name.
- This is the same route as [Get Group Link](/whatsapp/groups/get-group-link). The `reset=true` query parameter is what triggers a new link.
- The previous link stops being the current link and the returned link replaces it. Share the returned `invite_link`; it replaces the previous link.
- Only call this endpoint when you intend to reset the link. There is no separate reset route.
