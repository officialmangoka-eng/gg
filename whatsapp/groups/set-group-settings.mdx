## Endpoint

<Badge color="orange">PUT</Badge> `https://api.wapimax.com/whatsapp/v1/sessions/{session_id}/groups/{group_jid}/settings`

## Authentication

Every request must include your API key in the `X-API-Key` header. See [Authorization](/get-started/authorization) to create one.

| Header | Value | Required |
| --- | --- | --- |
| `X-API-Key` | Your WapiMax API key | Yes |
| `Content-Type` | `application/json` | Yes |
| `Accept` | `application/json` | Recommended |

## Path parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `session_id` | string | Yes | ID of the session |
| `group_jid` | string | Yes | JID of the group, ending in `@g.us` |

## Request body

All fields are optional. Send only the settings you want to change.

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `announce` | boolean / null | No | `true` means only admins can send messages |
| `locked` | boolean / null | No | `true` means only admins can edit subject, description and picture |
| `member_add_mode` | string / null | No | Who can add participants: `admin_add` or `all_member_add` |
| `member_link_mode` | string / null | No | Who can edit the invite link: `admin_link` or `all_member_link` |
| `membership_approval_mode` | string / null | No | Whether joining through the link requires admin approval: `off` or `on` |

## Response

<CodeGroup>

```json 200 OK
{
  "success": true,
  "message": "Group settings updated"
}
```

</CodeGroup>

### Response fields

| Field | Type | Description |
| --- | --- | --- |
| `success` | boolean | Whether the request succeeded |
| `message` | string / null | Human-readable result message |

## Errors

| Status | Description |
| --- | --- |
| `400` | Invalid request or missing required parameters |
| `401` | Missing or invalid API key |
| `403` | Access to this session is not permitted |
| `404` | Session or group not found |
| `429` | Plan usage quota exceeded or rate limit exceeded. |
| `503` | Session is not connected |

## Notes

- Send only the settings you want to change. Omitted fields keep their current values.
- Replace `{session_id}` with your session ID. Get it from [List Sessions](/whatsapp/sessions/list-sessions).
- Replace `{group_jid}` with the group JID. Get it from [List Groups](/whatsapp/groups/list-groups) or [Create Group](/whatsapp/groups/create-group).
- Use the group JID returned by the API. Do not use the group name.
