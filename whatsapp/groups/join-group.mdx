## Endpoint

<Badge color="blue">POST</Badge> `https://api.wapimax.com/whatsapp/v1/sessions/{session_id}/groups/join`

## Authentication

Every request must include your API key in the `X-API-Key` header. See [Authorization](/get-started/authorization) to create one.

| Header | Value | Required |
| --- | --- | --- |
| `X-API-Key` | Your WapiMax API key | Yes |
| `Content-Type` | `application/json` | Yes |
| `Accept` | `application/json` | Recommended |

## Path parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `session_id` | string | Yes | ID of the session |

## Request body

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `code` | string | Yes | Invite code or full invite URL |

## Response

<CodeGroup>

```json 200 OK
{
  "group_jid": "120363012345678901@g.us",
  "pending_approval": false
}
```

</CodeGroup>

### Response fields

| Field | Type | Description |
| --- | --- | --- |
| `group_jid` | string | JID of the joined group |
| `pending_approval` | boolean | `true` when the group requires admin approval and the join request is waiting |

## Errors

| Status | Description |
| --- | --- |
| `401` | Missing or invalid API key |
| `403` | Access to this session is not permitted |
| `429` | Plan usage quota exceeded or rate limit exceeded. |
| `503` | Session is not connected |

## Notes

- Replace `{session_id}` with your session ID. Get it from [List Sessions](/whatsapp/sessions/list-sessions).
- You may pass either the invite code (e.g. `AbCdEf123456`) or the full invite URL.
- When `pending_approval` is `true`, the session is not yet a member. An admin must approve the request.
