## Endpoint

<Badge color="blue">POST</Badge> `https://api.wapimax.com/whatsapp/v1/sessions/{session_id}/groups`

## Authentication

Every request must include your API key in the `X-API-Key` header. See [Authorization](/get-started/authorization) to create one.

| Header | Value | Required |
| --- | --- | --- |
| `X-API-Key` | Your WapiMax API key | Yes |
| `Content-Type` | `application/json` | Yes |
| `Accept` | `application/json` | Recommended |

## Path parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `session_id` | string | Yes | ID of the session |

## Request body

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `name` | string | Yes | Group name |
| `participants` | array | Yes | Phone numbers or JIDs of the people to add to the group. See [Participant formats](#participant-formats) |
| `member_add_mode` | string | No | Who can add participants: `admin_add` or `all_member_add` |
| `member_link_mode` | string | No | Who can edit the invite link: `admin_link` or `all_member_link` |
| `membership_approval_mode` | string | No | Whether join requests need admin approval: `off` or `on` |

<CodeGroup>

```json Example

  "name": "WapiMax Engineering",
  "participants": [
```

## Participant formats

Each entry in `participants` accepts the following formats.

| Format | Example | Description |
| --- | --- | --- |
| Phone number | `254712345678` | Full international number with country code |
| User JID | `254712345678@s.whatsapp.net` | WhatsApp user ID |
| LID | `123456789012345@lid` | WhatsApp Linked ID |

<Tip>
  Send plain phone numbers and WapiMax resolves them to the correct WhatsApp identifier for you. Use JIDs or LIDs when you already have them from another endpoint, such as [Get Group Info](/whatsapp/groups/get-group-info).
</Tip>

## Response

<CodeGroup>

```json 200 OK
{
  "group_jid": "120363012345678901@g.us"
}
```

</CodeGroup>

### Response fields

| Field | Type | Description |
| --- | --- | --- |
| `group_jid` | string | JID of the newly created group |

## Errors

| Status | Description |
| --- | --- |
| `400` | Invalid request or missing required parameters |
| `401` | Missing or invalid API key |
| `403` | Access to this session is not permitted |
| `404` | Session not found |
| `429` | Plan usage quota exceeded or rate limit exceeded. |
| `503` | Session is not connected |

## Notes

- Replace `{session_id}` with your session ID. Get it from [List Sessions](/whatsapp/sessions/list-sessions).
- Store the `group_jid` returned in the response for later group calls.
- Optional settings may be omitted or set to `null` if you do not wish to configure them.
