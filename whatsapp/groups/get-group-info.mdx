title: "Get Group Info"
description: "Fetch everything about a WhatsApp group in one request, including its name, description, settings, owner and participants with their roles."
---

## Endpoint

<Badge color="green">GET</Badge> `https://api.wapimax.com/whatsapp/v1/sessions/{session_id}/groups/{group_jid}/info`

## Authentication

Every request must include your API key in the `X-API-Key` header. See [Authorization](/get-started/authorization) to create one.

| Header | Value | Required |
| --- | --- | --- |
| `X-API-Key` | Your WapiMax API key | Yes |
| `Accept` | `application/json` | Recommended |

## Path parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `session_id` | string | Yes | ID of the session |
| `group_jid` | string | Yes | JID of the group |

### Response fields

| Field | Type | Description |
| --- | --- | --- |
| `addressing_mode` | string | Addressing mode, e.g. `pn` |
| `creation_time` | integer or null | Group creation time in Unix seconds |
| `creator` | string or null | Creator JID |
| `description` | string or null | Group description |
| `ephemeral_expiration` | integer or null | Disappearing messages timer in seconds; `0` means off |
| `is_announce` | boolean | `true` when only admins can send messages |
| `is_locked` | boolean | `true` when only admins can edit group info |
| `membership_approval` | boolean | `true` when join requests need admin approval |
| `participants` | array | Group members |
| `participants[].jid` | string | Participant JID |
| `participants[].role` | string | Participant role, e.g. `admin` or `member` |
| `participants[].phone_number` | string or null | Participant phone number |
| `subject` | string or null | Group name |

## Errors

| Status | Description |
| --- | --- |
| `401` | Missing or invalid API key |
| `403` | Access to this session is not permitted |
| `404` | Session or group not found |
| `429` | Plan usage quota exceeded or rate limit exceeded. |
| `503` | Session is not connected |

## Notes

- Replace `{session_id}` with your session ID. Get it from [List Sessions](/whatsapp/sessions/list-sessions).
- Replace `{group_jid}` with the group JID. Get it from [List Groups](/whatsapp/groups/list-groups) or [Create Group](/whatsapp/groups/create-group).
- Use the group JID returned by the API. Do not use the group name.
- Returns cached group information.
