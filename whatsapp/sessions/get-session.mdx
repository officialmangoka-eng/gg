## Endpoint

<Badge color="green">GET</Badge> `https://api.wapimax.com/whatsapp/v1/sessions/{session_id}`

## Authentication

Every request must include your API key in the `X-API-Key` header. See [Authorization](/get-started/authorization) to create one.

| Header | Value | Required |
| --- | --- | --- |
| `X-API-Key` | Your WapiMax API key | Yes |
| `Accept` | `application/json` | Recommended |

## Path parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `session_id` | string | Yes | Session ID |

## Response

```json 200 OK
{
  "id": "202610123",
  "name": "Chati",
  "phone_number": "254712345678",
  "push_name": "Felix Moreka",
  "status": "logged_in",
  "created_at": 1794302928,
  "updated_at": 1794339655,
  "last_connected_at": 1794339655,
  "is_logged_in": true,
  "provider": "whatsapp_web"
}
```

### Response fields

| Field | Type | Description |
| --- | --- | --- |
| `id` | string | Session ID |
| `name` | string | Session name |
| `phone_number` | string | Linked phone number |
| `push_name` | string | WhatsApp profile name |
| `status` | string | Session status |
| `created_at` | integer | Created time (Unix) |
| `updated_at` | integer | Last updated time (Unix) |
| `last_connected_at` | integer | Last connected time (Unix) |
| `is_logged_in` | boolean | Logged in state |
| `provider` | string | WhatsApp provider |

### Status values

| Status | Description |
| --- | --- |
| `disconnected` | Not connected to WhatsApp |
| `connecting` | Connection in progress |
| `waiting_for_qr` | Waiting for QR code scan |
| `waiting_for_pair_code` | Waiting for pairing code |
| `connected` | Connected to WhatsApp |
| `logged_in` | Connected and logged in |

## Errors

| Status | Description |
| --- | --- |
| `401` | Missing or invalid API key |
| `403` | Access to this session is not allowed |
| `404` | Session not found |
| `429` | Plan usage quota exceeded or rate limit exceeded. |
| `500` | Internal server error |
