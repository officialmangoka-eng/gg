title: "Delete Message"
description: "Delete a WhatsApp message for yourself or for everyone in a contact or group chat."
---

## Endpoint

<Badge color="blue">POST</Badge> `https://api.wapimax.com/whatsapp/v1/sessions/{session_id}/messages/{message_id}`

<Warning>
  **Notice**

  - In groups, you must be an admin to perform actions such as deleting another member's message for everyone. WhatsApp restrictions and limitations still apply.
</Warning>

## Authentication

Every request must include your API key in the `X-API-Key` header. See [Authorization](/get-started/authorization) to create one.

| Header | Value | Required |
| --- | --- | --- |
| `X-API-Key` | Your WapiMax API key | Yes |
| `Content-Type` | `application/json` | Yes |
| `Accept` | `application/json` | Recommended |

## Path parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `session_id` | string | Yes | ID of the session |
| `message_id` | string | Yes | ID of the message to delete |

## Request body

| Parameter | Type | Required | Default | Description |
| --- | --- | --- | --- | --- |
| `for_everyone` | boolean | No | `false` | Delete the message for everyone in the chat |
| `clear_media` | boolean | No | `true` | Remove media attached to the message |

### Delete options

| Option | `for_everyone` | Result |
| --- | --- | --- |
| Delete for me | `false` | Removes the message from your devices only. Other participants keep their copy. |
| Delete for everyone | `true` | Requests removal for all participants, subject to WhatsApp restrictions. |

<CodeGroup>

```json Delete for me
{
  "for_everyone": false
}
```

```json Delete for everyone
{
  "for_everyone": true
}
```

```json Keep media
{
  "for_everyone": false,
  "clear_media": false
}
```

## Response

<CodeGroup>

```json 200 OK
{
  "session_id": "202610123",
  "message_id": "3EB0C8F1A2B3C4D5E6",
  "target_message_id": "3EB0C8F1A2B3C4D5E6",
  "for_everyone": true,
  "result": "submitted"
}
```

</CodeGroup>

### Response fields

| Field | Type | Description |
| --- | --- | --- |
| `session_id` | string | ID of the session |
| `message_id` | string | Message ID from the request |
| `target_message_id` | string | ID of the message targeted for deletion |
| `for_everyone` | boolean | Whether delete for everyone was requested |
| `result` | string | Status of the delete request |

## Errors

| Status | Description |
| --- | --- |
| `400` | Invalid request or missing required parameters |
| `401` | Missing or invalid API key |
| `403` | Access to this session is not permitted |
| `404` | Session or message not found |
| `409` | WhatsApp rejected the deletion |
| `429` | Plan usage quota exceeded or rate limit exceeded. |
| `503` | Session is not connected |

## Notes

- Supports both contact and group chats.
- `for_everyone` defaults to `false`, and `clear_media` defaults to `true`.
- In groups, only admins can delete other members' messages for everyone.
- Replace `{session_id}` with your session ID. Get it from [List Sessions](/whatsapp/sessions/list-sessions).
- Obtain `message_id` from the send response or incoming webhooks.
