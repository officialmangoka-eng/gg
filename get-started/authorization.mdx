## 1. Create an API key

Before making API requests, you need an API key associated with your WapiMax account.

<Steps>
  <Step title="Sign in to WapiMax">
    Open your [WapiMax Dashboard](https://wapimax.com/dashboard) and sign in to your account.
  </Step>
  <Step title="Open API keys">
    Navigate to **Developer → API keys** or open the [API Keys Management](https://wapimax.com/dashboard/developer/api-keys) page directly.
  </Step>
  <Step title="Create your API key">
    Create an API key for the application that will communicate with WapiMax.
  </Step>
  <Step title="Copy your API key">
    Copy the generated API key and store it securely. You will use it to authenticate your API requests.
  </Step>
</Steps>

<Warning>
  Keep your API key private. Never expose it in public repositories, frontend JavaScript, browser applications, or client-side mobile code.
</Warning>

## 2. Authentication headers

Include the following headers in your API requests:

| Header | Value | Required |
| --- | --- | --- |
| `X-API-Key` | Your WapiMax API key | Yes |
| `Accept` | `application/json` | Recommended |

**Important:** WapiMax uses the `X-API-Key` header. Do not prefix your API key with `Bearer`.

## 3. Make your first authenticated request

The following example retrieves the WhatsApp sessions linked to your WapiMax account.

<CodeGroup>

```bash cURL
curl -X GET "https://api.wapimax.com/whatsapp/v1/sessions" \
  -H "X-API-Key: YOUR_API_KEY" \
  -H "Accept: application/json"
```

```javascript Node.js
const response = await fetch(
  "https://api.wapimax.com/whatsapp/v1/sessions",
  {
    method: "GET",
    headers: {
      "X-API-Key": process.env.WAPIMAX_API_KEY,
      "Accept": "application/json"
    }
  }
);

if (!response.ok) {
  throw new Error(`Request failed: ${response.status}`);
}

const data = await response.json();
console.log(data);
```

```php PHP
<?php

$curl = curl_init();

curl_setopt_array($curl, [
    CURLOPT_URL => "https://api.wapimax.com/whatsapp/v1/sessions",
    CURLOPT_RETURNTRANSFER => true,
    CURLOPT_HTTPHEADER => [
        "X-API-Key: YOUR_API_KEY",
        "Accept: application/json"
    ]
]);

$response = curl_exec($curl);

if ($response === false) {
    throw new RuntimeException(curl_error($curl));
}

$httpCode = curl_getinfo($curl, CURLINFO_HTTP_CODE);

curl_close($curl);

http_response_code($httpCode);
echo $response;
```

```python Python
import os
import requests

url = "https://api.wapimax.com/whatsapp/v1/sessions"

headers = {
    "X-API-Key": os.environ["WAPIMAX_API_KEY"],
    "Accept": "application/json"
}

response = requests.get(url, headers=headers)
response.raise_for_status()

print(response.json())
```

```go Go
package main

import (
    "fmt"
    "io"
    "net/http"
    "os"
)

func main() {
    req, err := http.NewRequest(
        http.MethodGet,
        "https://api.wapimax.com/whatsapp/v1/sessions",
        nil,
    )
    if err != nil {
        panic(err)
    }

    req.Header.Set("X-API-Key", os.Getenv("WAPIMAX_API_KEY"))
    req.Header.Set("Accept", "application/json")

    client := &http.Client{}

    resp, err := client.Do(req)
    if err != nil {
        panic(err)
    }
    defer resp.Body.Close()

    body, err := io.ReadAll(resp.Body)
    if err != nil {
        panic(err)
    }

    fmt.Println(string(body))
}
```

## 4. Understanding authentication errors

| HTTP status | Description |
| --- | --- |
| `401 Unauthorized` | The API key is missing or invalid. |
| `403 Forbidden` | The request is not permitted for the account or resource. |

When authentication fails, verify that:

- You copied the correct API key.
- The `X-API-Key` header is included in your request.
- Your application is using the correct WapiMax API endpoint.

## 5. API key security

Follow these practices when integrating WapiMax:

- Store API keys in environment variables or a secure secrets manager.
- Never commit API keys to GitHub or other public repositories.
- Never expose API keys in frontend applications.
- Avoid printing API keys in application logs.
- Use HTTPS for all API requests.
- Replace compromised keys through your API key management dashboard.
